# Document Type Selection

只读取与当前任务对应的章节。用户或项目已有结构优先，删除对读者决策没有帮助的章节。

## 需求 / Spec

- 背景、目标、非目标
- 用户和业务场景
- 已确认事实、待确认问题
- 推荐方案、必要的备选方案
- 接口、数据和流程影响
- 验收标准、验证方式、执行边界

## 设计方案

- 背景、约束和设计目标
- 当前方案或当前问题
- 推荐设计和关键流程
- 数据、接口与依赖影响
- 取舍、风险、验证计划
- 迁移和回滚

## 培训讲义 / 教材

- 适用对象与前置知识
- 学习目标和课程地图
- 核心概念与方法
- 示例、现场演示或练习
- 关键结论与常见误区
- 课后行动或延伸阅读

可以使用讲师提示、现场演示和学员练习 callout，但不要伪装成风险或证据状态。

## 架构扫描报告

- 扫描范围和已确认证据
- 架构摩擦候选及优先级
- Top Recommendation
- 候选详情和测试缝影响
- 未验证项与下一步

## Runbook / 排障手册

- 适用场景和症状识别
- 快速判断和排查步骤
- 临时止血与长期修复
- 验证方式
- 回滚、升级路径和依赖系统

## 发布说明 / 发布计划

- 发布目标和范围
- 必发、条件发、不发
- 前置条件、发布顺序和验证步骤
- 阻塞、回滚方案和观察项

## 复盘报告

- 摘要、时间线和影响范围
- 根因和处置过程
- 做得好的地方、问题与缺口
- 后续行动、责任人和截止时间

## 风险评估 / 分析报告

- 摘要和分析范围
- 已确认事实和关键发现
- 风险分级与影响面
- 建议方案、未确认项和下一步

## 选择规则

- 先判断用途，再选择一个主模板；不要拼接全部章节。
- 章节标题可以根据读者和问题调整，不强制逐字一致。
- 正式代码证据文档必须保留证据分层；培训材料不强行套证据模板。
