# Quality Gates

## Design Gate

通过条件：

- 页面范围清楚
- 主要状态清楚
- 产品页或品牌页的视觉方向清楚
- 非目标清楚

## Implementation Gate

通过条件：

- 修改发生在现有项目结构里
- 没无必要引入新依赖
- 复用了现有组件或明确说明为何没复用
- 文案不是空泛占位文本

## Responsive Gate

至少验证：

- 320-390px
- 平板
- 桌面

不能出现：

- 横向滚动
- 文本裁切
- 组件重叠

## Accessibility Gate

至少检查：

- 标题层级
- button / link 语义
- 表单 label
- focus-visible
- 可读对比度

## Verification Gate

结束前必须说明：

- 实际运行过什么命令
- 是否做了视觉检查
- 哪些路径未验证

没有验证，不说“已完成”。
