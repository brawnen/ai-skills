# 验证设计原型

读取 [原型协议](references/prototype.md)。先固定问题和观察判据，再选择逻辑/状态或 UI 分支；项目已有 design 时复用约束与适用设计能力。

实际运行代表操作并保存结论与可运行材料指针，未验证的部分如实说明。只要求探索时止于结论，正式实现与外部发布不由原型自动授权。

方法来源与本地适配见 [来源记录](references/upstream.md)，许可见 [MIT 许可](references/LICENSE.mattpocock)。
