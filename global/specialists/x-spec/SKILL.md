# 实施规格

读取 [规格协议](references/spec.md) 和需要的 [产物字段](references/artifacts.md#1-实施规格)。复用已确认需求与项目事实，不重新进行完整访谈。

需要模块形状判断时读取 [架构参考](references/architecture-design.md)；跨部署兼容、异步状态、迁移或信任边界有实际风险时读取 [跨边界设计](references/cross-boundary-design.md)；涉及前后端接口约定时复用 `x-api`。测试切入层存在取舍时，简短对比候选测试缝能捕获什么缺陷、会漏掉什么风险，锁定最窄稳定公共入口。

初版规格完成后按 [界面设计就绪检查](references/spec.md#界面设计就绪检查) 判断是否需先做页面/交互设计；存在缺口时主动说明下一步（调用全局 `x-ui` 定调），不能默认直接盲写界面。已有设计或无需界面的任务直接继续。

同一会话无需独立交接且相关设计已就绪时可附简短实施顺序直接进入实施；确需跨会话领取、依赖管理或并行集成时衔接 `$x-dev` 任务图协议。用户只要求规格时说明剩余设计缺口和建议后结束；已授权完整开发时复用授权推进。

方法来源与本地适配见 [来源记录](references/upstream.md)，许可见 [MIT 许可](references/LICENSE.mattpocock)。
