# 标杆产品设计基因速查卡（Brand Archetypes）

归纳方法参考 [`VoltAgent/awesome-design-md`](https://github.com/VoltAgent/awesome-design-md) 与 Google Stitch 设计系统规格。当非设计背景用户用“**做成类似某产品的感觉**”或选定某种气质方向时，提取下方对应的**色温比例、边框/阴影公式、圆角梯度与排版密度**作为起手基准，结合本项目真实业务调整。

> 边界：仅借用客观的视觉比例、空间秩序与工程参数，**严禁照搬他人的品牌名、Logo、商标口号或专有插画资产**。

---

## 1. Linear / 飞书式 —— 现代清爽工作台（B端后台 / 效率 SaaS 首选）

- **核心气质**：冷静、利落、高信息密度但毫不拥挤，靠精准对齐和超细微边框建立秩序，零多余装饰。
- **色彩公式**：
  - 浅色模式：画布 `#F8FAFC` / `#F9FAFB` → 主工作面 `#FFFFFF` → 主文字 `#0F172A` → 次要文字 `#64748B`；
  - 深色模式：画布 `#0B0C0E` → 表面 `#141519` → 浮层 `#1C1E24`；
  - 强调色：全屏克制使用单一品牌色（如靛蓝 `#5E6AD2` 或清脆钴蓝 `#2563EB`），主色面积占比 `< 5%`。
- **深度与圆角**：几乎不用大面积投影，统一用 `1px solid rgba(15, 23, 42, 0.08)` 低对比细边划分区域（浮层菜单才加轻微阴影）；小而利落的圆角（按钮/输入框 `6px`，卡片/面板 `8–10px`）。
- **排版与布局**：紧凑字阶（正文/表格 `13–14px`，表头/标签 `12px Medium`，模块标题 `16–18px Semibold`）；左侧紧凑固定导航（`220–240px`），右侧主内容满宽流式推进。

## 2. Stripe / Wise 式 —— 高信任商务与数据仪表盘（金融 / 结算 / 政企后台 / B2B 官网）

- **核心气质**：专业、可信、数字清晰、层次分明，既有现代精致感又让人放心把钱和核心业务交给它。
- **色彩公式**：清透冰白底 `#F6F9FC` + 纯白卡片 `#FFFFFF`；主文字用深海军蓝 `#0A2540`（**不用纯死黑 `#000000`**），次要文字用蓝灰 `#425466`；状态色语义极准（成功翠绿 `#057A55`、待处理琥珀 `#B45309`、异常深红 `#C81E1E`）。
- **深度与圆角**：标志性的双层微偏移干净柔影（`0 2px 5px rgba(50, 50, 93, 0.08), 0 1px 2px rgba(0, 0, 0, 0.05)`）替代生硬粗黑框；中等圆角（控件 `6–8px`，数据卡片 `10–12px`）。
- **排版与布局**：核心金额与 KPI 指标字号放大、字重加粗并强制 `tabular-nums` 等宽对齐，旁边必配清晰的单位、口径或环比微标签。

## 3. Apple HIG / Things 式 —— 清透原生移动工具（工具类 / 效率 / 个人管理手机 App）

- **核心气质**：安静、顺滑、一打开就会用，界面退后让任务本身站在最前面，单手大拇指操作毫无负担。
- **色彩公式**：标准原生分层背景——底层分组画布 `#F2F2F7` + 内嵌白色圆角列表组 `#FFFFFF`；主文字 `#1C1C1E`，次要说明 `#8E8E93`；单一清亮系统级强调色（如 `#007AFF` 或定制品牌主色）承载可点击文字与主动作。
- **深度与圆角**：连续平滑圆角（内嵌分组卡片 `12–16px`，底部大按钮 `12–14px`）；顶栏/底栏在滚动内容穿过时才呈现轻微半透明背景模糊，平时保持纯洁无界。
- **排版与布局**：顶部大标题（`28–34pt Bold`）随上滑自然收进导航栏；列表行高充足（`≥ 48–56pt`），组内用缩进细分割线，组间用背景色差自然留白。

## 4. Airbnb / 小红书式 —— 温润生活与内容卡片（消费 / 社区 / 预约 / 电商手机 App 与 C端 Web）

- **核心气质**：有温度、有烟火气、图文诱人、亲切不冰冷，逛起来轻松愉悦。
- **色彩公式**：纯白 `#FFFFFF` 或微暖白 `#FAF8F6` 画布；深暖炭灰文字 `#222222` + 柔和中灰 `#717171`；1 个温暖鲜明的情感主色（如珊瑚红 `#FF385C`、暖柿橙或牛油果绿），仅在核心转化按钮与收藏/点赞瞬间点亮。
- **深度与圆角**：亲和大圆角（封面图/主卡片 `16–20px`，胶囊筛选标签 `9999px`）；**去外框化卡片**——高质量封面图本身带圆角作为视觉边界，标题、价格和标签直接干净地排在图片下方，不给整张图文再套一层笨重的灰色大外框。
- **排版与布局**：图片比例统一克制（如 `4:3`、`1:1` 或 `4:5`），标题控制在 1~2 行，核心价格或关键卖点加粗突出。

---

## 5. Claude / Notion 式 —— 人文阅读与沉静创作（AI 助手 / 知识库 / 教育 / 写作类产品）

- **核心气质**：像翻开一本排版讲究的纸质笔记本，温和护眼、有书卷气与思考感，长时间阅读与输入不疲劳。
- **色彩公式**：低眩光暖羊皮纸底 `#FAF9F5` / `#F7F6F3` + 侧栏微深暖灰 `#F1EFE9`；暖墨色正文 `#1F1E1D`，次要文字 `#6B6860`；陶土橙、鼠尾草绿或深赭石等低刺眼自然强调色。
- **深度与圆角**：极轻薄平面感，依靠暖灰底色深浅区分主次区域，辅以 `1px solid rgba(31, 30, 29, 0.09)` 温润细线；柔和圆角（`8–12px`）。
- **排版与布局**：大标题可搭配优雅人文衬线体（或高辨识度温润无衬线），正文行宽严格收束在 `65–72ch`、行高舒展（`1.68–1.76`），段落呼吸留白充裕。

---

## 6. Vercel / Raycast 式 —— 极简锐利科技（开发者工具 / AI 基础设施 / 现代科技产品官网）

- **核心气质**：精密、克制、工程美学拉满，没有一丝赘肉，靠几何网格和真实运行的界面细节说话。
- **色彩公式**：高纯度中性灰阶（纯白 `#FFFFFF` / 极浅灰 `#FAFAFA`，或深邃碳黑 `#0A0A0A` / `#111111`），搭配高对比黑白主按钮（白底配黑实心主按钮，黑底配白实心主按钮），彩色只留给真实语法高亮与状态灯。
- **深度与圆角**：`1px` 发丝级贯穿网格线（Hairline Grid）构建版面骨架；克制小圆角（`6–8px`），严禁弥散彩色光晕与花哨渐变字。
- **排版与布局**：大字号紧凑字距标题（`-0.03em`）启用 `text-wrap: balance`，参数、版本号与延迟指标用等宽字体精准点缀，首屏直接嵌真实可交互组件演示。
