# 项目静态门禁

`init / audit` 与 `encode` 共用一个入口。模式从任务和仓库事实自动确定，不增加多余问答；优先复用项目现有工具链与检查入口，不造重型通用脚手架。

与已有能力分工：本 skill 负责静态检查底座与自定义规则沉淀；运行态自测底座与业务流验证由 `setup-verification` 负责；事后基于会话日志挖掘摩擦点由 `retro` 负责（其产出的 lint 候选可交由本 skill 落地）。

## 仓库取证与客观边界

行动前先读取四类项目事实：

1. 构建与依赖文件：语言栈、包管理器、工具链版本。
2. 目录与调用关系：模块分层、公共封装、边界入口与生成物。
3. 已有检查配置：linter、typecheck、测试命令、Git hooks 与 CI workflow。
4. 项目文档与历史失误记录：`README`、`AGENTS.md`、`CONTRIBUTING.md`、架构/开发规范中的明文红线，以及存量仓库近期 commits、reverts、review 评论和 workaround 注释中反复出现（≥2 次）的同类失误。

客观边界：接手项目时只提炼高确定性约束——语言/架构边界、分层依赖、已有公共组件或安全红线、文档明文硬规则。未写入代码和文档的隐性业务口径不得靠猜强加 lint（易误杀），留待研发中通过 `encode` 模式自然长出。

## Mode A：`init / audit`（接手项目建底座）

接手 0→1 空白项目、存量项目或开源项目，或需要选择跨语言工具链与接线方案时，读取 [三类项目适配与底座矩阵](references/project-modes.md)。
仓库包含服务端关系型数据库持久化或写 SQL 代码（如 `migrations`、`sqlc`、MyBatis Mapper、ORM raw SQL）时，读取 [SQL 写门禁协议](references/sql-guardrails.md)。

1. 判定项目类型（空白项目 / 存量项目 / 开源项目），从本次涉及的架构边界、正式业务契约或回归测试选取候选，对照 CI 实际执行的命令、解析器及扫描路径。已有覆盖直接复用，只有配置或测试样例时继续核实接线。空项目尚无语言或业务约定时仅记录已知约束。
2. 实施前先输出极简方案供确认：当前基线、拟接入/新增规则、误报风险、存量豁免（Baseline）或开源隔离策略、统一入口接线点。
3. 复用已有确认，在约定范围内实施。首次接入的自定义检查也须按[规则编码与验证](references/rule-encoding.md)验证实际扫描路径、合法对照和存量豁免。开源上游与本地 fork 的约束分别接入各自允许的范围。

## Mode B：`encode`（第二次原则沉淀规则）

修复或审查发现可复发的问题时，以行为、边界、组件或错误信号定向查提交差异、回退、评审和既有回归。给出当前实例与既往实例的出处，解释二者违反的同一约束。一次缺陷的提交、测试和评审属于同一实例。历史不可用或只查到一次时说明证据范围；已明确的项目契约可独立作为建规则的依据。

确认复发，或准备向 `AGENTS.md`/开发文档追加“禁止/必须”类规则时，读取 [规则编码与四件套协议](references/rule-encoding.md)。

1. 先过约束漏斗，优先选择最强可行层：`API/架构设计 → 类型系统 → 语言原生 lint / ast-grep → 轻量架构测试/校验脚本 → 文档`。仅当规则无法机械判定时才退回文档。
2. 若在日常修复盘中触发，先给出一句极简规则方案，经用户确认后再写入，避免过度打扰。
3. 按四件套交付：规则本体（优先 AST/类型匹配）+ 正反测试样例 + 面向 Agent 的三段式报错 + 规则生效后精简对应冗余文档。
4. 挂入项目统一检查入口；存量违规显式登记 Baseline 豁免，核实同文件新增的违规仍能被拦截。

## 交付与验证门槛

- 任何新接入底座或自定义规则，交付前必须实跑正反测试与项目统一检查入口，在隔离副本中通过统一入口对真实扩展名和生效路径运行违规、合法及适用的同文件增量对照，核对退出码及目标诊断；缺失工具或未执行项明确标为未验证或 blocked，不得编造通过结果。
- 禁止用行内 `disable` / `@ts-ignore` / `nolint` 或 `IMPORTANT: do not remove` 借口注释掩盖正确性/安全规则，也不得放宽规则掩盖新增违规（确需特例须标明原因、过期日期与人工批准）；不静默修改无关业务代码，不自动改动用户全局规则。
- 汇报最终结果时给出：项目类型/模式、失误归类与选层理由（为何更高层不可行）、落地文件与统一检查入口、正反测试与实跑证据、存量豁免清单及已精简/退场的文档条目。
