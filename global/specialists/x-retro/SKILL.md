# 开发环境复盘

读取 [复盘协议](references/retro.md)。对每个值得改进的问题，先核对当时适用的 skill 及实际运行记录，找出失效环节，再决定改触发条件、执行协议还是项目接线。需要调整指令时参考 [编写方法](references/authoring.md)。

机械错误优先交由 `x-guard` 修确定性检查与接线；需要主观判断的约定才进入规范。只要求分析时交付候选，明确授权实施时再改对应范围，不自动改用户全局偏好或写宿主记忆。

方法来源与本地适配见 [来源记录](references/upstream.md)，许可见 [MIT 许可](references/LICENSE.mattpocock)。
