# 编写供 Agent 使用的说明

只保留会改变执行决定的约束、项目事实与工具协议。常驻 description/AGENTS 每轮有成本；条件专属方法放参考，指针说明什么条件下读取，不能只有模糊的“参见文档”。

每个事实一处权威来源；命令、配置、目录等可廉价查到的信息不重复缓存。保留模型无法从配置得知的取舍原因与陷阱。完成条件必须可检查，不能只要求“理解充分”。

入口与复用协议分开：入口明确用户意图和停止点，协议说明实际决策。新增一个入口需要独立重复使用的价值，不能为命名对称或上游存在而增加。

修改指令先找实际失败证据，再选择修结构、补类型/lint/测试、更新条件指针或删除无效正文；避免无限累积禁令。普通技能制作优先遵循宿主可用的 skill-creator，不另安装同义包。
